# Code of Conduct

## Our Standard

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text is authoritative; what follows is the summary of what it asks and how it is applied here.

Participants are expected to be respectful, to accept technical criticism without taking it personally, and to keep discussion focused on the work. Harassment, personal attacks, discriminatory language, publishing others' private information, and sustained disruption are not acceptable.

Technical disagreement is welcome and expected. This repository holds its engineering and architectural claims to an uncompromising evidence standard ([`AGENTS.md`](AGENTS.md) §2) — demonstrating that a detector is incomplete, a gate is bypassable, a benchmark is skewed, or an invariant is violated is productive, on-topic conduct. Professional, constructive delivery is expected at all times.

## Scope

This Code of Conduct applies within all project spaces: GitHub issues, pull requests, discussions, code reviews, commit messages, and any communications representing the project.

## Enforcement

Report any conduct concerns to <nicolas@brousse.info>, or privately through GitHub's **Security → Report a vulnerability** form if preferred. Reports are treated with confidentiality.

Reports are reviewed and acted upon promptly. Responses range from guidance and requested corrections, to content modification or removal, to account blocking, in proportion to the severity of the behaviour.
